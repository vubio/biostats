SciPy / statsmodels
Run an analysis to see statistics, group summaries, library versions, and P values.

Pairwise comparison matrix

Pairs are evaluated as a single comparison family. Checking a row selects that bracket on the graph; the matrix remains available even if annotations are hidden.

04

Figure editor

Live controls. Export actual SVG vectors, not a screenshot.

Plotly SVG traces

Brackets appear after running statistics, never before. Asterisks and numerical labels use multiplicity-adjusted P values where applicable. For a single t test, the reported P value is unadjusted. Raw pairwise P values, if available, do not control the multiple-comparison false-positive rate.

SVG works well in Illustrator and Inkscape. Save as PDF through Chrome's print dialog.
05

Project history

Saved analyses do not get recalculated when software changes.

Uncheck for very large datasets. The project will retain statistics, an input fingerprint, original source-file metadata, and an unchanged/edited flag, but may not be independently recalculable.

Create or open a project folder to save analyses.

Each saved analysis preserves the test output, reproducibility report, graph settings, frozen SVG, and Python package versions. Numerical values can optionally be omitted, but that limits exact reproducibility. Loading historical entries only views the saved records.
